## Security invariants
1. User-approved server mutations only. No install through background health checks or planning.
2. Host key pinned. No fingerprint auto-accept, SSH password in logs or embedded root keys.
3. DNS tokens stored in Android Keystore. No automatic Cloudflare DNS write in Smart Manager.
4. Hiddify must remain on a dedicated VPS; DNS multiplexer is disabled until validated.
5. A service reporting `active` or a generated link is **not** a verified working VPN.
6. Psiphon `server-entry.dat` is stored separately from shareable profile fields.
7. Automatic Smart Connect must never treat a private Psiphon bootstrap as verified just because it is imported.
8. No PR merge, APK release, Cloudflare changes or real VPS installation without separate explicit approval.
